# remokey

远程键盘输入法 (Remote Keyboard)，用手机给电脑“打字”。

## I. 应用场景

电脑打字慢？借助手机的**语音转文字**功能，把手机变成电脑的输入法，大幅提升文字输入速度。

- **远程文本输入**：手机语音转文字后的中英文内容，发送到电脑当前焦点窗口
- **功能按键**：远程触发退格、回车、Tab、方向键
- **系统指令**：远程执行全选、复制、剪切、粘贴、撤销、清空

## II. 使用方式
1. 执行 `ipconfig` 命令查询桌面端主机的 **IPv4** 地址；
2. 配置 `remokey_config.ini` 中的 port 端口；
3. 双击启动 `remokey.exe` 可执行程序；
4. 使用移动端/手机连接网络，确保移动端的网络与桌面端主机处于同一局域网内；
5. 移动端打开浏览器访问 `<ipv4_address>:<port>` 链接，例如 `192.168.122.201:8888` （假设为此地址）;
6. 若连接成功，即可正常使用。

## III. 两种输入模式

| 模式 | 说明 |
|------|------|
| 草稿模式 | 编辑完成后点击发送，一次性推送 |
| 实时模式 | 输入即推送，无需点击发送 |

## IV. 状态显示

桌面端置顶悬浮窗口左上角实时显示：当前按键、控制指令、正在输入文本、等待输入操作等状态。
